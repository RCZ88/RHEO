- [2026-09-30] ELECTRON MAIN-PROCESS RULE: never use `cp.execSync`/`spawnSync` for user commands in `src/main.ts` IPC handlers — it blocks the whole event loop (all windows + all IPC) and reads to the user as an app crash. `terminal:exec` did this with a 30s timeout; a slow or stdin-waiting command froze DeskFlow solid. - [2026-09-30] ELECTRON HAS NO NATIVE FIND BAR — a keydown handler whose body is "let the browser handle Ctrl+F natively" is a silent feature-killer: in Electron that comment means the key does NOTHING. The real culprit was `NativeFindOverlay.tsx`, which full-screened `rgba(0,0,0,0.55)` + `backdropFilter: blur(6px)` (a curtain, not a lens) and merely LISTED matching text nodes without highlighting or scrolling. A working find bar = small fixed bar + `mark` elements injected by a TreeWalker (collect all matching text nodes FIRST, then mutate — the walker cannot survive its own surgery) + fully reversible teardown (`parent.normalize()`). **SECOND LESSON, cost a cycle:** when a MutationObserver rebuilds a derived DOM set, drive re-application of the ACTIVE item off a monotonic `version` counter, NOT off `setCount(n)` — React bails out of a setState with an unchanged value, so the active/highlight attribute silently vanished whenever the count stayed the same.
- [2026-09-30] THE COORDINATION TOOL WAS SILENTLY DEAD ON LINUX. `agent-coordination/coord.mjs` ended with `if (import.meta.url === \`file://${process.argv[1]}\`) main()`. `process.argv[1]` is RELATIVE (`agent/docs/.../coord.mjs`), so the guard compared `file:///run/media/.../coord.mjs` against `file://agent/docs/...` — never equal, `main()` never ran, and EVERY CLI command (`register`/`claim`/`status`/wrappers) returned `EXIT=0` with empty stdout and no registry write. **KEY LESSON: exit code 0 plus no output is NOT evidence a tool ran — and a coordination layer that no-ops defeats the entire purpose of having locks.** Fixed with `pathToFileURL(process.argv[1]).href === import.meta.url` (the plain template also breaks on any path containing a SPACE, which this repo's "App Tracker" path does). The library imports (`run-exclusive.mjs`, `db-guard.mjs`) were unaffected, so build/app/db locks WERE enforced — only the CLI was dead. Always `coord.mjs status` and confirm it prints `AGENTS (n)`, not just check `$?`.
