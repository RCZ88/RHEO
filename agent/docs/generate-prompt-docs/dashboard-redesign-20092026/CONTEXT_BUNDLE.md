## Design System Rules (LAMINAR constraints from `design/design.md`)

1. **No per-component bespoke shadows, radii, or borders** — use shared primitives
2. **No decorative gradients, neon glow, glass chrome** — flat zinc surfaces only
3. **No spring/bounce** — use ease-out or low-bounce spring
4. **One motion engine per element** — `motion/react` only, never mix with `framer-motion`
5. **Re-skin to `src/index.css` tokens** — never copy foreign palettes
6. **Max `rounded-xl`, `p-5` padding**
7. **Dark mode only**
8. **Geist + JetBrains Mono fonts**
