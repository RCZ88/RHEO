## Design Tokens (LAMINAR)

From `src/index.css`:
- Primary: green `#22c55e` (light) / amber `#fbbf24` (dark)
- Surface: `#09090b` canvas, `#18181b` card, `#27272a` elevated
- Radius: `10px` for cards/panels
- Font: Geist/Inter for UI, JetBrains Mono for numbers
- `rounded-[10px]` NOT `rounded-xl`/`12`/`3xl`
- NO `border` classes on cards (hairline token excepted)
- NO `backdrop-blur`, NO `shadow-*`
- NO hex color literals
