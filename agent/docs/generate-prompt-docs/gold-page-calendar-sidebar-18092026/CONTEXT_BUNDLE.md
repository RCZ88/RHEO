## Raw Request (user, verbatim intent)

The goal page of the Lifetime/Life page ("gold" tab): the design layout needs to be
fixed so it **maximizes the available width** (currently it does not maximize width on
big laptops — it is squished into a narrow centered column). The calendar should become
the **main focus**, taking roughly **1/3 of the width**, and should be **static/sticky
on one side** while the rest of the content **scrolls dynamically**. The user must be
able to **set whether the calendar is on the left or the right side**. The design must
be intentional, with purpose, human-centric UI/UX. Use the generate-prompt skill and the
frontend UI/UX skills.

## Problem Statement

1. **Width is not maximized.** Two overlapping max-width wrappers strangle the page:  
   - `LifePage.tsx:552` wraps `<GoldPage />` in `<motion.div className="max-w-5xl mx-auto">` (~1024px).
   - `GoldPage.tsx:1480` root is `className="space-y-4 max-w-6xl mx-auto"` (~1152px).
   - On a big laptop the content column is therefore ~1024–1152px wide with huge empty margins.
2. **Broken grid.** `GoldPage.tsx:1504` uses `grid grid-cols-1 lg:grid-cols-3 gap-4`, but the
   right column at `GoldPage.tsx:1744` carries `xl:col-span-7` — **invalid for a 3-column grid**,
   so the right column (MonthWall + ScheduleSyncCard + DeadlinesCard) actually renders as a
   **full-width row below** the left column at `xl` instead of sitting beside it. The intended
   "calendar on the right" already exists but is visually broken.
3. **Calendar is not the focus.** The calendar (MonthWall) is not sticky, not sized ~1/3, and
   currently drops below everything.
4. **No side preference control.** There is no setting for calendar left/right placement.

## Design System (LAMINAR tokens — binding)

- **Surfaces:** monochrome zinc. Dark mode base `--bg-primary:#09090b`, elevated card
  `--color-card:#18181b`, borders `--color-border:#27272a` (`src/index.css` dark @theme, lines ~193-232).
- **Signal hue:** ONE hue per surface. Gold page's existing accent = amber
  (`--color-primary:#fbbf24` dark; gold accent usages `amber-400`, `amber-500/15` currently).
- **Radii:** 8 / 12 / pill only (`rounded-md:6? no — LAMINAR allows 8/12/pill`; existing code uses `rounded-lg`/`rounded-xl`).
- **Fonts:** Inter (UI) + JetBrains Mono (data/mono) + Space Grotesk (display). Max 2 per view.
- **No** glassmorphism on chrome, no decorative glow, no spring/bounce motion.
- **`prefers-reduced-motion`** honored (MonthWall already does).
- Chart/data-viz only via the chart registry — none needed here.
