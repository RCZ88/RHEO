# The Parser's Anatomy
@mastery L2
@prereq the-systems-lens

Welcome to the parser sandbox. This node tests basic prose, tables, math, and flowcharts to ensure the foundational structure of the lesson is compiling correctly. When building complex applications, verifying the base layer prevents cascading failures in downstream rendering.

| Feature | Status |
|---------|--------|
| Prose   | Active |
| Table   | Active |
| Mermaid | Active |

```mermaid
flowchart TD
    A["Start"] --> B["Parse Frontmatter"]
    B --> C{"Valid YAML?"}
    C -->|"Yes"| D["Parse Nodes"]
    C -->|"No"| E["Throw Error"]
    D --> F["Render UI"]
```

The mathematical complexity of parsing $N$ nodes with $B$ blocks each is bounded by:

$$
\mathcal{O}(N \cdot B \cdot \log(B))
$$

::: callout tip
Always verify your YAML frontmatter before debugging node content. A missing `chapter` field will fail the schema validator before the parser even looks at your Markdown.
:::

# Advanced Rendering and Interactivity
@mastery L4
@prereq debugging-as-a-science

This node tests advanced directives including code, figures, illustrations, layers, and open quizzes. These elements transform static text into interactive learning experiences.

import sys

def test_parser_features():
    features = ["code", "table", "figure", "illustration", "callout", "layer", "quiz"]
    parsed_count = 0
    for feature in features:
        parsed_count += 1
        print(f"Successfully parsed: {feature}")
    
    print(f"Total features verified: {parsed_count}")
    return parsed_count

if __name__ == "__main__":
    test_parser_features()

::: layer L4 deeper
### Deep Dive: AST Generation
The parser converts the .lmd text into an Abstract Syntax Tree (AST) before rendering.
Each directive block becomes a specialized node in the tree, allowing the frontend
to apply specific React components for `chart`, `mermaid`, and `code` blocks.
:::

::: quiz open L4
Explain why the Lyceum parser uses Lesson Markdown (.lmd) instead of JSON for authoring.
rubric: Should mention that code samples, diagrams, and prose contain backticks, quotes, and newlines that easily corrupt hand-written JSON. Markdown removes this failure class, allowing the compiler to handle structure.
:::
